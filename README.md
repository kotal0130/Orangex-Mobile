# Orangex

Orangex is a code editor designed specifically for smartphones, based on Termux.

For more details, see: Orangex documentation

## Features of Orangex

### Mobile Programming

Leverages Termux to build a Linux environment on your phone, providing a versatile programming experience similar to a computer, supporting Python, C++, JavaScript, Java, and many other languages.

### Graphical Interface

Provides a file manager, code editor, and quick terminal execution interface, all designed for mobile and user-friendly on phones.

### Small Footprint

Termux runs commands using Android's native Linux system without installing an additional Linux OS. Orangex renders its interface via the web, so there’s no need to install extra graphical environments, keeping memory usage low.

### Start from Zero

Beginner-friendly programming tutorials are carefully designed—no computer required, you can start your programming journey with just a smartphone. Hello, world!

## Installation

### Download the App

**Download and install the Termux package and the Orangex package.**

- [Termux installation package](https://box.nju.edu.cn/f/0065095f93504ba5831c/?dl=1)
- [Orangex installation package](https://box.nju.edu.cn/f/340effcc1ddb4419be93/?dl=1)

### Run the Automated Installation Script

**Make sure you have a stable internet connection during this process!**  
**Running the script will take about 15~30 minutes and use about 100 MiB of data.**

Copy the code below and paste it into the `Termux` app:

```sh
sh -c "$(curl -fsSL https://blog.orangex4.cool/demo/orangex/install.sh)"
```

**Press Enter and wait a few seconds. If the screen starts displaying text, the installation script is running.**  
**You’ll be prompted for "Termux is requesting storage access"—choose Allow.**

**When the screen looks as shown in the image, the script is finished. Congratulations!**

**Successful installation hints: 1. Different colors. 2. Green tilde `~` at the lower left.**
